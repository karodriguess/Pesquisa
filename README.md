# Pesquisa sobre criação de conteúdo

Pesquisa rápida, em formato de onboarding, para entender como empreendedores, autônomos, criadores de conteúdo e profissionais de marketing produzem conteúdo e divulgam seu trabalho hoje.

São 7 perguntas de múltipla escolha, uma por tela, com barra de progresso. Ao final, a pessoa pode deixar o @ do Instagram para receber novidades e compartilhar a pesquisa com amigos.

Feito com React, Vite e Tailwind CSS, com as respostas armazenadas no Supabase.
